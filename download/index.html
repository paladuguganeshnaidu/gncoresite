GET STARTED

Install only what you need.

The candidate commands below become available after approved publication. The currently public PyPI package is a separate release.

python -m pip install --pre gncore==7.0.0rc1
gncore version
gncore export --specific neural-networks
gncore verify

Preview a full migration

gncore export --all --prune-retired --dry-run
gncore export --all --prune-retired
gncore verify
gncore audit

Pruning retires only unchanged inventory-managed old categories and retains a full backup. Custom edits and untracked folders are preserved; conflicts stop the update.

Portable archive

gncore export --all --output gncore-developer-skills.zip

The host agent must support and enable the standard skill format. Exporting does not install a model, frameworks, browser tools or credentials.
