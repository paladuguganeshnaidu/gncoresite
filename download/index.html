01 / INSTALL BY OPERATING SYSTEMPICK YOUR TERMINAL

Your machine.
Your setup.

These commands use a Python virtual environment for isolation, avoiding system Python conflicts. Choose the tab matching your operating system and paste the steps into a terminal.

Windows 10 / 11 · PowerShell — install Python 3.10+ first if py --version fails. These commands run without activating a PowerShell script.

WINDOWS / POWERSHELL
py --version
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip gncore
.\.venv\Scripts\gncore.exe version
.\.venv\Scripts\gncore.exe list apps

In PowerShell, use .\.venv\Scripts\gncore.exe while the virtual environment is not activated.

macOS · Terminal (zsh/bash) — ensure Python 3.10+ is available. A virtual environment avoids externally managed Python installation issues.

MACOS / ZSH OR BASH
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip gncore
gncore version
gncore list apps

Run source .venv/bin/activate in later terminal sessions before using the gncore command.

Linux / Windows Subsystem for Linux — ensure python3 and its venv support are installed using your distribution package manager.

LINUX / SHELL
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip gncore
gncore version
gncore list apps

For Ubuntu / Debian, install the Python venv package matching your Python version if python3 -m venv is unavailable.

Install results depend on the available PyPI release and your local Python environment. The GNCore GitHub source currently identifies version 4.0.0; verify the installed version with gncore version.

03 / MORE INSTALLATION OPTIONSCHOOSE YOUR WORKFLOW
OPTION 01 / ONE-STEP PIP

Python package install

When you already have an appropriate managed Python environment, install with pip.

PYTHON / PIP
python -m pip install --upgrade gncore

On macOS and Linux, python3 -m pip may be appropriate. Prefer a virtual environment to avoid modifying system packages.

OPTION 02 / ISOLATED GLOBAL CLI

pipx

If pipx is installed, keep GNCore isolated while placing its executable on your PATH.

ISOLATED CLI / PIPX
pipx install gncore
pipx upgrade gncore

Set up pipx first using its official instructions and check that your shell can find the GNCore executable.

OPTION 03 / CONTRIBUTING

Editable source checkout

For developers modifying GNCore, install from the public GitHub repository rather than using a published wheel.

SOURCE / DEVELOPMENT
git clone https://github.com/paladuguganeshnaidu/gncore.git
cd gncore
python -m pip install -e .
gncore version

Run inside your own Python 3.10+ virtual environment.

OPTION 04 / CHATGPT SKILLS

One-skill ZIP export

Create a ZIP per skill and manually upload it through the supported ChatGPT Skills interface. This is not a direct ChatGPT integration or automatic sync.

CHATGPT / ZIP EXPORT
gncore export --app chatgpt --skills company-ceo --output company-ceo.zip

Check ChatGPT account eligibility and workspace upload requirements before using.

MAINTAIN YOUR INSTALLATION
