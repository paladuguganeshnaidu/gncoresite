12 SKILL LIBRARY WORKFLOWS

Your assistant.
More structure.

GNCore searches and exports portable SKILL.md folders. Copy the folders you choose into an assistant’s documented skills directory; GNCore does not detect or modify assistant applications.

01 / CATALOG WORKFLOWSUSE THE GNCORE CLI
01

Search by task

gncore search "clean data"
02

Browse domain packs

gncore list domains
03

List all skills

gncore list skills
04

List specialist categories

gncore list categories
05

Inspect one skill

gncore show train
06

Export one skill

gncore export --skills train --output train.zip
07

Export selected workflows

gncore export --skills train preprocess evaluate --output ml-skills.zip
08

Export all 403 skills

gncore export --all --output gncore-skills.zip
09

Portable skill file

gncore show train
10

Portable ZIP bundle

gncore export --skills web-development --output web-development.zip
11

Python library access

python -c "from gncore import get_skill; print(get_skill('train').prompt)"
12

Check package version

gncore version

Using exported skills

GNCore writes only the ZIP path you provide. Copy selected SKILL.md folders to an assistant’s documented skills directory. It does not scan, configure, or install into application folders.
