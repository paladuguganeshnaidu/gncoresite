METHOD / SOURCES / LIMITS

What the numbers mean.

One check is one criterion.

168/173 means 168 applicable review criteria passed. Criteria are pooled across 29 fully reviewed non-UI categories; categories have slightly different denominators. Every category’s count is available in the table.

Compare within an IDE.

The historical comparison uses the same tasks in each condition. Manual review was unblinded; Copilot Auto was not fixed to one model. There is one task per category and no repeated-trial estimate or no-skill control.

Keep trials separate.

The historical pilot predates the current release. Known-task repairs and withdrawn development quality scores are excluded. An incomplete later fresh-context comparison provides no balanced quality ranking.

Inspect the source.

Thirty reference guides were pinned across fourteen repositories, including Anthropic, Vercel, Supabase and specialist projects. Each task uses its relevant reference; these are not aggregate scores for those companies.

Current catalog and package

30 categories, 374 workflows and 1,660 declared resources. 153 passed, 0 failed, 1 skipped in the recorded local package suite. Resource hashes and package tests verify files and software behavior; they do not certify arbitrary AI output.
