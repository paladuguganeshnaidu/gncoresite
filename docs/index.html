A small CLI. Concrete evidence.

Browse locally, ask for an explainable routing hint, and verify the exact files that get installed.

gncore list skills
gncore list domains
gncore list workflows
gncore search "neural network"
gncore route "Check neural network gradients"
gncore show neural-networks
gncore evaluate --validate
gncore audit

Evaluation scope

The corpus has a normal, underspecified and boundary scenario for each of the 30 categories. The offline runner checks recorded selection, constraints and artifact presence. Human review and external execution remain separate and cannot be certified by a structural pass.

Project context

The optional route context file permits stack, brand, audience and preferred_skills. It is an explicit small JSON brief; GNCore does not scan secrets or unrelated project files.

gncore route "Build a website" --context ./project-brief.json
