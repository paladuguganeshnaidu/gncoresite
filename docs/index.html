01 / QUICK START

Search, export, invoke.

Install the published GNCore Python package, verify the version you received, then choose skills for your assistant. The repository version is 5.0.0; the version available on PyPI may differ.

GNCORE CLI
gncore search "clean data"
gncore list domains
gncore export --skills sheet-clean --output sheet-clean.zip
gncore show train

Then, in an assistant that supports native invocation, start a request with /sheet-clean followed by your dataset, context, constraints, and success criteria.

02 / EXPORT SKILLS

Export and copy

Workspace is useful when copying a skill into one project’s documented skills directory. User is an assistant-specific location you choose when copying the exported folder. Choose the skill IDs you need, export them as a ZIP, and copy selected SKILL.md folders into an assistant’s documented skills directory.

Example: gncore export --skills company-ceo --output company-ceo.zip

03 / CHATGPT

Export one skill as a ZIP.

Export a portable skill bundle with this command:

SKILL EXPORT
gncore export --skills company-ceo --output company-ceo.zip

The ZIP contains a standard company-ceo/SKILL.md folder and a README. Copy the folder to the skills directory supported by your assistant. This is a file export, not an application integration.

04 / VALIDATION

Inspect before relying.

Use gncore version to check the package, gncore search or gncore show to explore skills, and gncore export to write a selected or complete ZIP. Upgrade the Python package with python -m pip install --upgrade gncore.

05 / IMPORTANT LIMITS

Skills guide work. They don't do it alone.

GNCore is reusable instruction content, not an autonomous software agent or a cloud-hosted AI execution service. Results depend on assistant functionality, tool permissions, provided context and human checks. Healthcare, legal and financial workflows are support for qualified review, not replacements for professional judgment.

06 / SOURCE & LICENSE

Source verification status.

The public GNCore repository confirms the MIT license in its LICENSE file, and documents Python 3.10+ in pyproject.toml. Read the source usage guide for the current CLI.
