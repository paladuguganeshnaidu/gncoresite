06 / FAQGOOD QUESTIONS

The basics,
answered.

GNCore is a library of reusable instructions. Here are the important boundaries before using it.

Is GNCore an autonomous AI agent?+

No. GNCore provides skill instructions for an assistant to follow. It does not independently execute projects, connect to tools, or guarantee results.

Do I need all 403 skills?+

No. Search the catalog, choose the relevant skill IDs, and export only the workflows you need.

Where do exported skills go?+

Copy the exported SKILL.md folders into the skills directory documented by your assistant. GNCore creates a ZIP at the output path you select and does not write to assistant directories.

Does every assistant support slash commands?+

No. Slash invocation is available only where the target assistant supports native skill invocation. Otherwise follow that target’s skill loading behavior.

What does Cloudflare host here?+

Only the public, static GNCore product website and catalog data—not the Python CLI, an AI model, or an execution backend.

Can I use exported skills with ChatGPT?+

GNCore exports portable SKILL.md folders in ZIP files. Copy a folder to the documented skills directory of an assistant that supports this format; GNCore does not integrate directly with ChatGPT or other applications.
